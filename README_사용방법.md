# 디스플레이 측정값 자동 정리 v2.2.0

FIB·SEM 이미지에 적힌 측정값을 찾아, 사람이 확인한 후 Excel에 정리하는 프로그램입니다.
이미지와 OCR 결과는 PC 내부에서 처리합니다. EXE 배포본은 Python과 Tesseract를 별도로 설치하지 않습니다.

## 처음 실행할 때

1. 새 ZIP을 다운로드합니다. 예전 v2.1.0 폴더와 섞지 말고 새 폴더에 압축을 풉니다.
2. 안에 ZIP이 한 번 더 있으면 그 ZIP도 압축을 풉니다.
3. DisplayMeasurementAutomator 폴더를 엽니다. _internal 폴더도 함께 있어야 합니다.
4. RUN_EXE_SELF_TEST.bat을 더블클릭합니다. 검사 결과가 나올 때까지 기다립니다.
5. 통과 메시지가 나오면 DisplayMeasurementAutomator.exe를 더블클릭합니다.
6. 창 제목 끝이 v2.2.0인지 확인합니다. EXE 파일 하나만 다른 폴더로 옮기면 안 됩니다.

## 측정값을 Excel로 만드는 순서

1. '이미지 파일 추가' 또는 '폴더 추가'를 누릅니다.
2. 분석 이미지들을 선택합니다. JPG, PNG, TIF/TIFF 등의 형식을 사용할 수 있습니다.
3. '전체 검사'를 누릅니다. 작은 글자는 확대해서 검사하므로 이미지 크기에 따라 시간이 걸립니다.
4. 더 작은 글자가 계속 빠지면 '더 작은 글자 정밀 검사'를 켜고 다시 검사합니다.
5. '후보·값 검토'를 엽니다. 사용할 이미지만 선택합니다.
6. 미리보기와 목록의 숫자·단위·포인트명을 원본과 비교합니다. 확인 필요 값은 수정하거나 제외합니다.
7. 샘플 이미지에서 높이와 각도 그룹의 앞뒤 순서를 정합니다.
8. '검토 완료' 후 'Excel 저장'을 누르고 저장할 위치를 선택합니다.

## 간단해진 Excel

기본 결과는 다음처럼 보입니다. 아래 값은 설명용 예시입니다.

| 시료번호 | 파일명 | H1 (nm) | Top-W (µm) | A1 (°) |
|---|---|---:|---:|---:|
| 1 | 1-01.png | 167.5 | 2.35 | 15.2 |
| 2 | 2-01.png | 170.5 | 2.55 | 16.4 |
| 평균 | | 169.0 | 2.45 | 15.8 |

- 첫 시트 '측정 데이터': 시료번호, 파일명, 측정값, 마지막 평균 행만 표시합니다.
- 두 번째 시트 '전체 검출 목록': OCR 원문, 단위, 위치, 제외 사유 등을 확인하는 곳입니다.
- 이미지 한 장당 한 행입니다. 값 개수는 이미지별로 달라도 됩니다.
- 숫자는 숫자 셀로 저장하며 단위는 열 제목에 표시합니다.
- nm와 µm는 높이 그룹이지만 크기가 다른 단위입니다. 같은 열에 단위가 섞이면 평균을 계산하지 않습니다.
- 미확정/불일치 값이 남은 열도 평균 대신 '값 확인 필요'로 표시합니다. 프로그램에서 값을 확인·수정한 후 다시 저장하세요.
- 빈 셀은 0이 아닙니다. 실제 0은 평균 계산에 포함됩니다.
- 예전처럼 처리시간·원본경로·설정까지 필요한 경우 '상세 Excel'을 켠 후 저장합니다.

## v2.2.0에서 바뀐 점

- 색상 측정선을 찾아도 이미지 전체의 추가 글자를 항상 검사합니다.
- 좌우 가장자리에 여백을 붙여 OCR하고, 작은 영역을 겹쳐 확대 검사합니다.
- 원본·흑백 대비 강화·색상 분리 판독을 사용합니다.
- 측정선이 없는 작은 색상 글자도 별도로 탐색합니다. 세로 글자는 양쪽 회전을 검사합니다.
- 가까이 있는 같은 값 두 개를 하나로 합치던 위험을 줄였습니다.
- 하단 각도값을 위치만 보고 제외하지 않습니다. 스케일바 선이나 장비정보 근거가 있는 항목을 제외 후보로 남깁니다.
- 기본 Excel을 2개 시트로 단순화했습니다.

## 결과를 확인하는 방법

OCR은 흐리거나 손상된 글자를 항상 정확하게 읽는 기술이 아닙니다. 읽힌 숫자가 있어도 원본 대조가 필요합니다.
판독 방법마다 숫자가 다르면 확인 표시를 남깁니다. 스케일바 자동 분류도 검토 화면에서 포함/제외를 바꿀 수 있습니다.
회사에서는 이전에 누락됐던 좌우 각도·작은 글자·연한 글자가 있는 원본부터 시험해 주세요.
이미지를 외부에 보내지 않아도 전체 정답 개수·누락 개수·오독 개수·걸린 시간을 기록하면 개선에 도움이 됩니다.
자체 시험 범위와 남은 한계는 TEST_REPORT.md에 있습니다.

## 소스 코드로 실행하는 경우

EXE 사용자에게는 이 단계가 필요 없습니다. 개발용 Python 환경에서는 requirements.txt를 설치하고
python display_measurement_automator_v2.py로 실행합니다.

개발용 시험: python -m unittest -v test_measurement_ocr_v2 test_regressions_v22

공개 샘플 두 장이 없는 환경에서는 해당 샘플 시험 3개만 생략하며 합성 OCR 시험은 실행합니다.
