# 디스플레이 측정값 자동 정리 v2.3.0

FIB·SEM 이미지에 적힌 측정값을 찾아, 사람이 확인한 후 Excel에 정리하는 프로그램입니다.
이미지와 OCR 결과는 PC 내부에서 처리합니다. EXE 배포본은 Python과 Tesseract를 별도로 설치하지 않습니다.

## 처음 실행할 때

1. 새 ZIP을 다운로드합니다. 예전 버전 폴더와 섞지 말고 새 폴더에 압축을 풉니다.
2. 안에 ZIP이 한 번 더 있으면 그 ZIP도 압축을 풉니다.
3. DisplayMeasurementAutomator 폴더를 엽니다. _internal 폴더도 함께 있어야 합니다.
4. RUN_EXE_SELF_TEST.bat을 더블클릭합니다. 검사 결과가 나올 때까지 기다립니다.
5. 통과 메시지가 나오면 DisplayMeasurementAutomator.exe를 더블클릭합니다.
6. 창 제목 끝이 v2.3.0인지 확인합니다. EXE 파일 하나만 다른 폴더로 옮기면 안 됩니다.

## 측정값을 Excel로 만드는 순서

1. '이미지 파일 추가' 또는 '폴더 추가'를 누릅니다.
2. 분석 이미지들을 선택합니다. JPG, PNG, TIF/TIFF 등의 형식을 사용할 수 있습니다.
3. '전체 검사'를 누릅니다. 작은 글자는 확대해서 검사하므로 이미지 크기에 따라 시간이 걸립니다.
4. 더 작은 글자가 계속 빠지면 '더 작은 글자 정밀 검사'를 켜고 다시 검사합니다.
5. '후보·값 검토'를 엽니다. 사용할 이미지만 선택합니다.
6. 미리보기와 목록의 숫자·단위·포인트명을 원본과 비교합니다. 확인 필요 값은 수정하거나 제외합니다.
7. 샘플 이미지에서 그룹 순서와 그룹 안의 값 순서를 정합니다. 아래 설명을 따라 해 보세요.
8. '현재 순서를 기준으로 설정'을 눌러 다른 이미지와 Excel에 쓸 순서를 정합니다.
9. '검토 완료' 후 'Excel 저장'을 누르고 저장할 위치를 선택합니다.

## 새 기능: 같은 그룹 안에서 값 순서 바꾸기

예를 들어 목록에 각도 두 개 다음으로 높이 값 3, 4, 5가 보인다고 생각해 보세요.
높이 값의 순서를 3, 5, 4로 바꾸려면 다음처럼 합니다.

1. '전체 검사'가 끝나면 '후보·값 검토'를 누릅니다.
2. 왼쪽에서 기준으로 사용할 샘플 이미지 한 장을 누릅니다.
3. 오른쪽 '현재 이미지 측정값'에서 지금 5번째에 있는 높이 값의 행을 한 번 누릅니다.
4. '같은 그룹 안:' 옆의 '값 위로'를 한 번 누릅니다. 이 값과 그 위 높이 값의 자리가 바뀝니다.
5. 더 이동하려면 '값 위로'나 '값 아래로'를 다시 누릅니다. 각도 그룹으로 넘어가지는 않습니다.
6. '현재 순서를 기준으로 설정'을 누릅니다. 다른 이미지와 Excel에도 이 순서가 적용됩니다.
7. '검토 완료'를 누른 다음 'Excel 저장'을 누릅니다.
8. 다음 작업에서도 이 순서를 쓰려면 메인 화면의 '기준 순서 저장'으로 JSON 파일을 저장하세요.
9. 다음 실행 때 '기준 순서 불러오기'로 이 JSON을 선택합니다. 검사 전이나 검사 후에 불러올 수 있습니다.

| 바꾸려는 것 | 누를 버튼 | 동작 |
|---|---|---|
| 높이 값 3, 4, 5 → 3, 5, 4 | 5번째 값 선택 → 값 위로 | 현재 이미지에서 같은 그룹 안의 두 값 자리를 바꿈 |
| 높이 그룹 전체를 각도보다 먼저 | 높이 값 선택 → 그룹 위로 | 모든 이미지의 그룹 순서를 바꾸고 그룹 안의 순서는 유지 |
| 바꾼 순서를 다른 이미지·Excel에 적용 | 현재 순서를 기준으로 설정 | 현재 이미지의 그룹 및 값 순서를 공통 기준으로 설정 |
| 다음 실행에서도 다시 사용 | 검토 완료 → 기준 순서 저장 | 기준 순서를 JSON 파일로 저장 |

- 화면의 '순서' 숫자는 위치를 나타냅니다. 이동 후에는 1, 2, 3…으로 다시 표시됩니다.
  예전 5번 값이 4번 자리에 오므로 **포인트명 또는 수치값**으로 이동한 항목을 확인하세요.
- nm와 µm는 같은 높이 그룹 안에서 이동할 수 있습니다. 단위 자체나 측정 숫자를 바꾸지는 않습니다.
- 값 이동은 현재 이미지에 먼저 적용됩니다. 공통 순서로 쓰려면 반드시 '현재 순서를 기준으로 설정'을 누르세요.
- 포인트명이 있으면 같은 이름, 없으면 이미지의 상대 위치로 다른 이미지와 연결합니다. 다른 구조의 이미지는 대응을 확인하세요.
- 다른 이미지에 없는 기준 값은 Excel에서 빈칸으로 남습니다. 새로 발견한 값은 해당 그룹의 기준 값들 뒤에 추가합니다.
- 제외된 값은 먼저 '값 사용 전환'으로 포함한 후 이동하세요. 그룹 첫 값은 더 위로, 마지막 값은 더 아래로 옮겨지지 않습니다.
- 검토창을 다시 열거나 값을 수정해도 기존 값들의 변경된 순서를 유지합니다. '취소'하면 검토창에서 바꾼 내용을 반영하지 않습니다.

## v2.3.0에서 바뀐 점

- '값 위로 / 값 아래로'를 추가해 그룹 안의 순서를 바꿀 수 있습니다.
- 그룹 이동·값 수정·검토창 재열기 때 값 순서를 이미지 위치순으로 되돌리던 부분을 수정했습니다.
- 기준 저장·다시 불러오기·다른 이미지 적용·Excel 열 생성에서 사용자가 지정한 순서를 유지합니다.
- 기준에 없는 추가 값은 같은 그룹 뒤에 배치합니다. 다른 명시적 포인트명을 빈 기준 위치에 잘못 연결하지 않습니다.
- OCR 모델과 판독 알고리즘은 v2.2.0과 같습니다. 이 버전은 순서 편집 및 결과 정리 개선입니다.

## 간단해진 Excel

기본 결과는 다음처럼 보입니다. 아래 값은 설명용 예시입니다.

| 시료번호 | 파일명 | H1 (nm) | Top-W (µm) | A1 (°) |
|---|---|---:|---:|---:|
| 1 | 1-01.png | 167.5 | 2.35 | 15.2 |
| 2 | 2-01.png | 170.5 | 2.55 | 16.4 |
| 평균 | | 169.0 | 2.45 | 15.8 |

- 첫 시트 '측정 데이터': 시료번호, 파일명, 측정값, 마지막 평균 행만 표시합니다.
- 두 번째 시트 '전체 검출 목록': OCR 원문, 단위, 위치, 제외 사유 등을 확인하는 곳입니다.
- 이미지 한 장당 한 행입니다. 값 개수는 이미지별로 달라도 됩니다.
- 숫자는 숫자 셀로 저장하며 단위는 열 제목에 표시합니다.
- nm와 µm는 높이 그룹이지만 크기가 다른 단위입니다. 같은 열에 단위가 섞이면 평균을 계산하지 않습니다.
- 미확정/불일치 값이 남은 열도 평균 대신 '값 확인 필요'로 표시합니다. 프로그램에서 값을 확인·수정한 후 다시 저장하세요.
- 빈 셀은 0이 아닙니다. 실제 0은 평균 계산에 포함됩니다.
- 예전처럼 처리시간·원본경로·설정까지 필요한 경우 '상세 Excel'을 켠 후 저장합니다.

## v2.2.0에서 바뀐 점

- 색상 측정선을 찾아도 이미지 전체의 추가 글자를 항상 검사합니다.
- 좌우 가장자리에 여백을 붙여 OCR하고, 작은 영역을 겹쳐 확대 검사합니다.
- 원본·흑백 대비 강화·색상 분리 판독을 사용합니다.
- 측정선이 없는 작은 색상 글자도 별도로 탐색합니다. 세로 글자는 양쪽 회전을 검사합니다.
- 배경이 고른 영역에서는 작은 흑백 글자도 별도로 찾아 일반 글자 검출의 누락을 보완합니다.
- 가까이 있는 같은 값 두 개를 하나로 합치던 위험을 줄였습니다.
- 하단 각도값을 위치만 보고 제외하지 않습니다. 스케일바 선이나 장비정보 근거가 있는 항목을 제외 후보로 남깁니다.
- 기본 Excel을 2개 시트로 단순화했습니다.

## 결과를 확인하는 방법

OCR은 흐리거나 손상된 글자를 항상 정확하게 읽는 기술이 아닙니다. 읽힌 숫자가 있어도 원본 대조가 필요합니다.
판독 방법마다 숫자가 다르면 확인 표시를 남깁니다. 스케일바 자동 분류도 검토 화면에서 포함/제외를 바꿀 수 있습니다.
회사에서는 이전에 누락됐던 좌우 각도·작은 글자·연한 글자가 있는 원본부터 시험해 주세요.
이미지를 외부에 보내지 않아도 전체 정답 개수·누락 개수·오독 개수·걸린 시간을 기록하면 개선에 도움이 됩니다.
자체 시험 범위와 남은 한계는 TEST_REPORT.md에 있습니다.

## 소스 코드로 실행하는 경우

EXE 사용자에게는 이 단계가 필요 없습니다. 개발용 Python 환경에서는 requirements.txt를 설치하고
python display_measurement_automator_v2.py로 실행합니다.

개발용 시험: python -m unittest -v test_measurement_ocr_v2 test_regressions_v22 test_ordering_v23

공개 샘플 두 장이 없는 환경에서는 해당 샘플 시험 3개만 생략하며 합성 OCR 시험은 실행합니다.
